# 分层情节结构（总纲 → 卷 → 章 → 场景）

> **分层原则**：每层只回答一个问题，且**只有该层的负责人能在该层做决策**。
> 写正文时只看「场景层」，做剧情决策时只看「卷层」，判断方向时只看「总纲层」。
> 混层看 = 上下文爆炸 + 决策混乱。

---

## 层与层的接口

| 层 | 回答什么 | 颗粒度 | 谁写 | 何时冻结 | 单章写作时是否载入 |
|---|---|---|---|---|---|
| **L1 总纲** | 这本书讲什么、终局是什么 | 1 页 | 你 | 开书前冻结 | ✅ 只载压缩版（≤300 字） |
| **L2 卷纲** | 这一卷结束时要变成什么局面 | 1 卷 = 1 页 | 你 | 上一卷写完前 | ✅ 只载**当前卷**（≤500 字） |
| **L3 章纲（事件卡）** | 这一章主角要达成什么 | 1 章 = 10 行 | 你 | 写本章前 | ✅ 全载（≤300 字） |
| **L4 场景卡** | 这一场戏里谁在哪、争什么 | 1 场景 = 6 行 | 你 / AI 起草你改 | 动笔前 | ✅ 全载（≤200 字/场景） |
| **L5 正文** | 实际文字 | 2000–2600 字/章 | 你（AI 只出草稿） | —— | —— |

## L2 · 卷纲模板（一卷一文件：`vol-01.md`）

```
第 X 卷 · 卷名
─────────────────────────────
【卷目标】主角本卷要拿到什么（一个可验证的结果）
【卷末格局跃迁】卷末世界和卷初比，变了什么（必须写，否则读者觉得白看）
【本卷主对手】编号 + 强于主角的一点
【势力格局变化】谁升 / 谁降 / 谁新出现
【A/B/C 线配比】A 线 60% / B 线 25% / C 线 15%（本卷实际配比：   ）
【本卷新埋伏笔】F0xx（计划回收：第 X 卷 / 第 X 章）
【本卷回收伏笔】F0xx（埋于第 X 章）
【本卷支线收束】收了哪条 / 保留哪条
【三线交汇高潮章】第 X 章（每 50–80 章一次）
【章节区间】第 X – X 章（约 X 万字）
─────────────────────────────
卷内章纲索引：（章号 | 章名 | 一句话 | 钩子类型）
```

**卷结构参考（起承转合）**：

| 卷 | 功能 | 字数参考 | 卷末必须发生 |
|---|---|---|---|
| 第1卷 | 立局 | 15–25 万 | 主角获得立足点，格局跃迁一次 |
| 第2卷 | 扩张 | 20–30 万 | 势力/身份升级，出现更强对手 |
| 第3卷 | 对抗 | 25–35 万 | 与主要敌对势力正面碰撞 |
| 第4卷 | 真相 | 20–30 万 | 世界观真相部分揭晓 |
| 第5卷 | 终局 | 15–25 万 | 核心矛盾解决，收束支线 |

> 短篇/中篇按比例压缩，但「卷末必须发生什么」这条不能省。
> **铁律：前 30 章细纲必须在开书前写完**——前 30 章是数据决定期，不能即兴。

## L3 · 章纲（事件卡）模板

```
第 X 章 | 拟定章名
─────────────────────────────
【本章目标】主角要达成什么（一句话，必须是可验证的动作）
【在场人物】C001、C003
【时间/地点】D+03 14:00 / L002
【核心事件】发生了什么（2–3 句）
【转折点】哪一刻局面变化
【爽点】本章爽点类型（≥1 个，开篇期 ≥2）
【章末钩子】用了哪一式 + 强度 ★★★★
【信息增量】读者本章新知道了什么（没有 = 注水章）
【伏笔】埋 F0xx / 强化 F0xx / 回收 F0xx
【字数目标】2000–2600
【禁止事项】本章不能出现什么（防越界：例"本章 C007 不得得知 F001"）
─────────────────────────────
```

## L4 · 场景卡模板（一章通常 2–4 个场景）

```
场景 X/Y
【地点】  【时间】  【在场】
【场景目的】这场戏存在的理由（删了会影响剧情吗？不会 = 砍掉）
【冲突】谁想要什么，谁挡着
【结果】局面变成什么样（必须有变化，平的场次就是水）
【信息增量】读者/主角在这场次里新得到什么
【情绪落点】结束时读者该是什么情绪
```

## 三条线的管理（A/B/C）

```
A 线 · 主线（主角目标）      占 60%
B 线 · 副线（情感/成长/势力） 占 25%
C 线 · 悬念线（大伏笔/真相）  占 15% —— 但决定"追读到完结"
```

**铁律：A 线永远不能让位。** B 线服务于人设厚度，C 线服务于长线期待。

**线程失控五大预警信号**：

| 信号 | 修法 |
|---|---|
| 线头 > 5 条 | 合并或砍掉（**开一关一**原则） |
| B 线篇幅 > A 线 | 把 B 线并入 A 线事件 |
| 连续 30 章无 C 线 | 插一个 C 线小提示 |
| 伏笔超 50 章未提 | 立即轻点一次 |
| 支线人物抢戏 | 支线事件必须服务于主角目标 |
