# 线程台账（支线与线索管理）

> 支线是长篇的氧气，也是长篇的溺水源。
> **硬约束：同时开启的支线 ≤ 2 条；每 30 章必须收束 1 条；新开一条必须先关一条（开一关一）。**

---

## 1. 线程总表

| 编号 | 线程名 | 归属线 | 开启章 | 目标/悬念 | 计划收束章 | 状态 | 占比 |
|---|---|---|---|---|---|---|---|
| T001 |  | A/B/C |  |  |  | 开启 / 推进中 / 已收束 / 已砍 |  |

**状态定义**：
- 开启：已埋但未展开
- 推进中：正在占篇幅
- 已收束：给了明确结果
- 已砍：明确放弃（必须在正文里给个交代，不能凭空消失）

## 4. 收束手法清单（避免"草草了事"）

| 手法 | 适用 |
|---|---|
| **兑现收** | 前面承诺的东西真的给了（读者最买账） |
| **代价收** | 收束时主角付出一个代价（提升厚重感） |
| **反转收** | 收束时改变这件事的含义（高价值） |
| **遗留收** | 主线结束但留一个小尾巴，接入下一条线（续命用，慎用） |
