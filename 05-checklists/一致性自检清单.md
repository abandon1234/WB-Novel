# 一致性自检清单（三张，分别在不同时机跑）

> 资源库口径：2026-09 ｜ 方法来源：18 号《长篇一致性四大台账》、43 号《伏笔回收工程》、17 号《力量体系》。
> **用法**：不要凭感觉过一遍，逐条打勾。任一条不过 → 改完再往下走。

---

## 清单 A · 动笔前（2 分钟，防止"写完才发现方向错了"）

```
□ 本章目标是一句话可验证的动作吗？（不是"推进感情"这种无法验证的）
□ 本章目标与当前卷目标有直接因果吗？（没有 = 离卷，删掉或改）
□ 本章在场人物的卡都取出来了吗？逐条看过「降智护栏」三不做吗？
□ 本章涉及的能力表现，在力量体系档位表内吗？有没有越档？
□ 本章时间接续上一章吗？有没有跨天/跨地需要交代行程？
□ 本章要埋/收的伏笔，编号和章号写进事件卡了吗？
□ 本章禁止事项写了吗？（例："C007 不得在本章得知 F001"）
□ 上下文包是否 ≤4500 字？超了压了吗？
□ 名词规范表带了吗？（防同物异名）
□ 本章的事件是否必须由主角完成？（不是 → 主角边缘化预警）
```

---

## 清单 B · 完稿后（5 分钟，发给读者前最后一道闸）

```
【时间线】
□ 章内时间单调递增？跨天有交代？
□ 与上一章摘要的"时间线增量"首尾相接？
□ 伤/毒/闭关的恢复期到了吗？没到就活蹦乱跳 = 崩
□ 昼夜、季节、天气描写与时间一致？
□ 并行线切换处，另一线时间对齐了吗？

【人物】
□ 每个人物的决策，能通过他卡上的「降智护栏三不做」吗？
□ 有没有人物知道了他不该知道的信息？（信息污染是最隐蔽的崩）
□ 对话遮住名字能分辨出是谁吗？（句长/用词/态度）
□ 有没有人突然变强/突然变蠢而没有交代？
□ 主角成长是认知层面的吗？（不只是数字变大了）
□ 女性角色有自己的目标与选择吗？（不是只为男主存在）

【能力】
□ 本章的战力表现，在档位表的"该档上限表现"内吗？
□ 越级战斗：是否同档内？跨档的话代价明写了吗？本卷第几次？
□ 新出现的能力/道具，是临时加的还是台账里有的？（临时加 = 战力通胀起点）
□ 反派是否至少在一个具体维度强于主角？

【伏笔与线程】
□ 埋的伏笔够隐蔽吗？（有没有"意味深长地"之类提示）
□ 有没有该强化而未强化的伏笔（>50 章未提）？
□ 回收的伏笔给情绪回报了吗？（只揭晓不回报 = 空转）
□ 支线同时开启 ≤2 条？新开的是否关了一条？

【节奏】
□ 前 300 字有新信息或新动作？
□ 每 300 字有一次新信息/新动作/新情绪？
□ 章末钩子强度 ≥★★★？
□ 有没有段落能整段删掉而不影响剧情？（有 = 注水）
□ 语言有人类参差感吗？（AI 味指纹 ≥3 项 → 打回）
```

---

## 清单 C · 每 20 章体检（30 分钟，防中期崩盘）

```
□ 主角实力增长与档位表一致吗？
□ 有没有"突然变强 / 突然变蠢"的角色？
□ 待回收伏笔 > 5 个？（是 = 预警，必须安排回收章节）
□ 支线 > 2 条？
□ 这 20 章有一个明确的阶段性目标达成吗？
□ 时间线全段单调吗？（跑 tools/ctx.py check）
□ 主角口头禅/行为标签前后一致吗？
□ 有没有整段可删而不影响剧情的章节？
□ 连续 10 章没出场的配角？（收束或删除）
□ 连续 30 章无 C 线提示？
□ 名词规范表有没有新增同物异名？
□ 本 20 章里，主角有没有做过违背「降智护栏」的事？
```

**自动化部分**（能机器做的别用肉眼）：
```bash
python tools/ctx.py check            # 时间单调 / 人物复活 / 伏笔超期 / 字数区间
python tools/ctx.py check --fore     # 只看伏笔健康度
```

## 崩盘抢救 SOP（已经崩了怎么办）

```
Step 1  停止推进新剧情，做一次全量台账复盘（ctx.py check + 人工过一遍四大台账）
Step 2  列出所有不一致点，分三类：
        ① 可回撤 → 后续章节自然修正，不解释（解释反而放大）
        ② 难回撤 → 用「设定补丁」圆回来，补必须有前文伏笔支撑
        ③ 圆不了 → 用剧情转折把矛盾点作废（失忆 / 规则变化 / 叙述者不可靠）
Step 3  补丁登记进 00-故事圣经.md 变更日志，写清受影响章号
Step 4  后续 10 章内安排一次高质量高光，重建读者信任
Step 5  更新台账，重新立写作纪律（下次 20 章体检提前到第 10 章）
```

## 五类最高频崩点（记住这五个就够了）

| 崩点 | 典型表现 | 防线 |
|---|---|---|
| **时间线冲突** | 三天前的伤这章好了；两地瞬移 | 时间线台账 + 待恢复项表 |
| **性格漂移** | 谨慎的人突然莽撞；善良的人突然下狠手 | 人物卡「降智护栏三不做」 |
| **能力膨胀** | 每卷都破一次上限，反派越来越不够打 | 档位表 + 越级代价 + 本卷次数上限 |
| **信息污染** | 某人知道了剧情需要他知道、但逻辑上不该知道的事 | 事件卡「禁止事项」栏 |
| **伏笔烂尾** | 埋了忘、收了没回报 | 伏笔台账 + 每 20 章体检 |
