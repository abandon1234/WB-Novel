# 借鉴库总纲（Reference Library）

> **一句话原则：借结构，不借文字；借功能，不借外壳；借节奏，不借句子。**
>
> 本目录里的**一切都是别人的**。它存在的意义不是给你抄，是给你**拆出可复用的结构**，然后换掉全部外壳变成你的。
> 借鉴库与你的原创稿之间，是**单向阀**：只能 `借鉴库 → 移植审批 → 我的设定`，反向禁止，直接复制禁止。

---

## 一、为什么必须物理隔离（不只是整洁问题）

| 污染类型 | 表现 | 后果 |
|---|---|---|
| **设定污染** | 把参考书的设定细节当成"我自己想好的"写进故事圣经 | L0 元规则里混进别人的东西，后面全书跟着歪 |
| **表达污染** | 金句、口癖、比喻、段落节奏长进你的文风里 | 读者一眼看出"这本像那本"；反洗稿风险 |
| **记忆污染** | 写到 80 万字，分不清哪句是自己写的、哪句是看来的 | 无法自证原创，维权与签约都被动 |
| **证据污染** | 借鉴库与稿件同目录、同命名，无法证明先后与来源 | 出事时拿不出证据链 |

**结论：隔离不是为了防君子，是为了在你需要证明"这是我写的"时，拿得出东西。**

---

## 二、五道隔离墙

| # | 墙 | 具体做法 |
|---|---|---|
| 1 | **目录隔离** | 借鉴内容只放 `10-reference/`，与 `01-story-bible/`（我的设定）、`03-chapters/`（我的正文）物理分离，禁止互相 include |
| 2 | **单向流动** | 借鉴 → 我的设定，**必须经过 `90-移植审批台账.md` 登记**；未登记的借鉴一律视为不存在，写进正文也要回退 |
| 3 | **命名隔离** | 借鉴侧统一 `R0x` 前缀（R01、R02…）；我的侧是 `C0xx`（人物）/ `L0xx`（场景）/ `F0xx`（伏笔）/ `S0x`（势力）/ `T0xx`（线程）。**看到 R 开头就知道是别人的** |
| 4 | **上下文隔离** | `ctx.py pack` 默认**不读借鉴库**；只有显式 `--ref R01` 才载入，且**只载「可移植清单」，绝不载原文片段** |
| 5 | **扫描隔离** | `ref.py scan` 每章扫我的正文 vs 借鉴库禁区语料，连续相同 ≥12 字即报警 |

**额外一条铁律**：借鉴库里的原文片段**只用于比对，绝不用于生成**。给 AI 的提示词里，只能出现"抽象后的功能描述"，不能粘贴原文让它"改成这样"。

## 三、三层转化法（借鉴的唯一合法路径）

| 层 | 可借鉴度 | 内容举例 | 转化要求 |
|---|---|---|---|
| **L1 结构层** | ✅ 可直接借 | 三幕节拍、卷末格局跃迁、升级阶梯、钩子密度配置、冲突模型（弱者-压制者-规则） | 抽象成"功能一句话"，换掉全部外壳后使用 |
| **L2 功能层** | ⚠️ 必须改造 | 人物功能位（镜像型/递刀型/消耗型）、场景功能（打脸/误会/重逢/背叛）、势力功能（伪装盟友/体制压制） | 至少换 3 个维度：身份、动机、关系、道具 |
| **L3 表达层** | ❌ 禁止 | 任何具体文字、金句、口癖、人名地名、道具描写、段落节奏 | 一律不碰；进了正文就是事故 |

### 转化四步

```
① 抽象化  把桥段写成一句"功能描述"
   例：「主角在众人面前被轻视，随后用一个只有内行才懂的细节完成反转」
   ——注意这里已经没有了任何原文、人名、道具、场景

② 换外壳  时代 / 职业 / 道具 / 关系 / 场景，至少换 3 个维度
   参考书：现代职场 · 拍卖会 · 古董 · 师徒
   我  的：未来废土 · 黑市   · 芯片 · 竞争对手

③ 重写    用我的世界逻辑重新推导，而不是"翻译"
   —— 关键：这个桥段在我的世界里"为什么必然发生"？答不上来就别写

④ 反向自检 遮住来源书名，把成品给不知情的人看
   —— 还能认出是哪本书 → 转化不合格，回第②步
```

## 四、三源融合原则（防止"整本像某一本"）

任何一条进入我书的借鉴，必须同时满足：

```
□ 至少融合了 3 个不同来源（或 2 个来源 + 我自己的原创设计）
□ 自身改造度 ≥ 60%（不是"改了名字"，是"换了逻辑"）
□ 单一来源在「我的设定」中占比 ≤ 25%
□ 全书对任何单一作品的依赖度 ≤ 40%
```

**单一来源占比怎么算**：`90-移植审批台账.md` 里按来源编号统计条目数，`ref.py report` 会自动算并预警。

## 五、七维基因卡（每本参考书拆这七项）

对每本参考书，拆以下七维——**注意第七维的纪律**：

| 维度 | 拆什么 | 纪律 |
|---|---|---|
| 1 核心钩子 | 一句话卖点，读者为什么点进来 | 记"钩子类型"，不记原话 |
| 2 首章必胜动作 | 前 200 字做了什么、第 1 章结尾给了什么 | 记动作序列 |
| 3 结构节拍 | 卷/关键节点/转折章的位置与功能 | 记节拍表（可借） |
| 4 爽点配方 | 爽点类型 + 出现频率 + 铺垫长度 | 记配方比例（可借） |
| 5 钩子配置 | 章末钩子类型分布、强度分布 | 记密度（可借） |
| 6 人设张力 | 主角的反差结构、配角功能分工 | 记**功能位**，不记人名 |
| 7 金句调性 | 金句的**句式类型**（短句反问 / 对比 / 留白） | ⚠️ **只记类型，绝不记原句**。原句进禁区清单 |

---

## 六、禁区清单（每本书一份，反洗稿的比对语料）

每本参考书必须建 `04-禁区清单.md`，登记：

```
【绝不能出现在我正文里的原文片段】（用于 ref.py scan 比对）
```
（把原文片段放进 ``` 代码块，脚本会整段读取）

| 类型 | 登记内容 |
|---|---|
| 原句 / 金句 | 原文照录（仅作比对语料） |
| 人物口癖 | 口头禅、高频句式 |
| 专有名词 | 人名、地名、功法名、组织名、道具名 |
| 标志性桥段 | 一两句功能描述 + 出处章号 |

**这份清单的作用是"反过来用"**：它不是给你抄的目录，是给你**避开的雷区图**。`ref.py scan` 会拿它逐字扫你的正文。

## 七、拿到一本新参考书的六步（标准动作）

```
① 登记  在 01-溯源索引.md 加一行（编号/书名/作者/赛道/我打算借什么）
② 建夹  python tools/ref.py add --code R02 --title "书名" --track "赛道"
③ 拆书  填 00-七维基因卡.md + 01-结构节拍表.md（只填结构与功能）
④ 标界  填 03-可移植清单.md（能用的）+ 04-禁区清单.md（不能碰的）
⑤ 移植  抽象化 → 换外壳 → 重写 → 在 90-移植审批台账.md 逐条登记
⑥ 成稿  写完一章跑 python tools/ref.py scan，确认无表达污染
```

## 八、数值红线（超过就回退重写）

| 指标 | 红线 | 检查方式 |
|---|---|---|
| 与任一来源的**连续相同文字** | ≤ 12 字 | `ref.py scan --min-gram 12` |
| 单章与任一来源的**结构重合度** | ≤ 40% | 人工 + `ref.py report` |
| 单一来源在全书设定中的**条目占比** | ≤ 25% | `ref.py report` |
| 单一来源的**可移植条目被采用率** | ≤ 50%（不能一本抄半本） | 人工 |
| 移植时**自身改造度** | ≥ 60% | 台账自评 + 四步转化第④步 |
| 借鉴库内容进入**上下文包** | 默认 0，显式 `--ref` 时才载入 | `ctx.py pack` |

## 九、五个常见翻车

| 翻车 | 原因 | 防线 |
|---|---|---|
| 「我就借了一句」 | 金句是辨识度最高的东西，一句就能被认出 | L3 表达层全禁，无例外 |
| 「改了名字就算原创」 | 外壳没换，逻辑也没换 | 四步转化第③步：必须能回答"为什么在我的世界里必然发生" |
| 「我忘了这句是从哪来的」 | 没登记溯源 | 单向流动：没进台账的借鉴视为不存在 |
| 「三本书都写这个，那我也写」 | 把套路当原创 | 三源融合 + 自身改造 ≥60% |
| 「AI 帮我改一下就不像了」 | AI 改写不降低侵权风险，且违反治理红线（内环禁止 AI） | 内环（人设/冲突/转折/爆点/名场面/金句）必须你本人定 |

---

## 十、合规底线

- 借鉴**结构、功能、节奏**是行业通行做法；复制**表达、桥段细节、人物关系组合**不是。
- AI 只可用于外环（检索、校对、润色、起名）与中环（骨架/初稿，须深度改写 ≥60%）。**内环严禁 AI**：核心人设、主线冲突、关键转折、情绪爆点、名场面、金句。
- 涉及具体作品的版权判断属于法律问题，本文为创作管理方法论，**不构成法律意见**；如涉及出版、改编、签约的实质性借鉴，请咨询专业人士。
