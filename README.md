## 每日三步循环

```bash
PY="C:/Users/35310/.workbuddy/binaries/python/versions/3.13.12/python.exe"

# ① 装配上下文（写之前）
"$PY" tools/ctx.py pack --chapter 12 --out 04-context/pack-0012.md

# ② 写正文（用 06-prompts/每章提示词模板.md 的 P3，只喂 pack 文件 + 事件卡）

# ③ 归档（写完）
#    生成摘要 → 写入 03-chapters/summaries/ch0012.md
"$PY" tools/ctx.py roll --chapter 12    # 并入滚动上下文
"$PY" tools/ctx.py check                # 一致性硬检查
"$PY" tools/ref.py scan                 # 反洗稿扫描（有借鉴库时必跑）
```

## 借鉴一本新书（六步）

```bash
# ① 在 10-reference/01-溯源索引.md 加一行
# ② 建夹
"$PY" tools/ref.py add --code R02 --title "书名" --track "赛道"
# ③ 拆书：填 00-七维基因卡.md + 01-结构节拍表.md（用 06-prompts/借鉴分析提示词.md 的 RA/RB/RC）
# ④ 标界：03-可移植清单.md（能用的）+ 04-禁区清单.md（不能碰的）
# ⑤ 移植：抽象化 → 换外壳 → 重写 → 逐条登记进 90-移植审批台账.md
# ⑥ 成稿：
"$PY" tools/ref.py scan && "$PY" tools/ref.py report
```

## 五条铁律

1. **写在文件里，不写在心里** —— 记忆不可靠。
2. **正文与摘要分离** —— 写下一章只读摘要，不读正文。
3. **改剧情，不改人设** —— 剧情逼角色违背「降智护栏」时，改的是剧情。
4. **借结构，不借文字** —— 借鉴库只出"功能描述"，原文只进禁区清单。
5. **单向流动** —— 借鉴 → 移植审批台账 → 我的设定；没登记的借鉴视为不存在。
