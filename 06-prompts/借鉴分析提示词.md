# 借鉴分析提示词模板（RA–RE）

> **使用前提**：这些模板只用于**分析结构与功能**，绝不用于生成近似原文。
> **给 AI 的输入纪律**：粘贴参考书原文片段时，只用于让 AI 归纳，且**要求 AI 输出抽象描述，禁止回显原文**。
> **合规红线**：不得让 AI 对原文做"同义改写""洗稿"——中环允许的是骨架/初稿（须深度改写 ≥60% 且由人重写），不是改写他人表达。

---

## RA · 拆七维基因卡

```
角色：你是网文结构分析师。你只输出结构与功能描述，不输出原文。

输入：《书名》的【章节文本/情节梗概】，赛道【X】。

任务：输出七维基因卡，字段如下：
1 核心钩子：钩子类型 + 一句话卖点（用你自己的话概括，不得引用原文）
2 首章必胜动作：前 200 字的动作序列 + 第 1 章结尾给了什么
3 结构节拍：卷数、每卷功能、卷末格局跃迁、关键转折章位置
4 爽点配方：类型分布（打脸/升级/收获/认可/解气 各占多少）+ 铺垫长度 + 每章密度
5 钩子配置：章末钩子类型分布 + 强度分布 + 强钩子间隔
6 人设张力：主角反差结构（表层 vs 内核）+ 配角**功能位**分工 + 反派压迫感来源
7 金句调性：只描述**句式类型**（短句反问/对比/留白/悖论/数字罗列）与出现位置

硬约束：
① 全文不得出现原文引用、原句摘录、人物名与道具名（用"主角""对手A"等代号）
② 每一维必须是可迁移的抽象描述，不依赖该书的设定
③ 若某项无法抽象，写"无法抽象，属表达层"并跳过
④ 输出 ≤800 字
```

## RB · 结构节拍表提取

```
角色：你是网文结构工程师。

输入：《书名》的【卷/章结构信息】。

任务：输出三张表：
表1 全卷节拍：卷 | 章区间 | 卷功能 | 卷末格局跃迁 | 主对手
表2 关键节点：章号 | 节点功能（一句话）| 节拍类型（首胜/重创/真相/背叛/结盟/身份揭晓/资源到手）| 铺垫章数
表3 节奏曲线：区间 | 每章爽点数 | 钩子强度 | 冲突密度 | 情绪基调

约束：
① 只写"发生了什么功能"，不写"发生了什么情节"
② 节点功能必须能脱离该书设定独立成立
③ 不得出现原文、人名、道具名
④ 最后追加「我认为可迁移的三条节拍」，每条一句话，并说明迁移到我的【赛道/设定】时该换成什么
```

## RC · 人物功能位提取

```
角色：你是网文人物结构分析师。

输入：《书名》的【人物与关系信息】。我的设定：【我的赛道 / 主角表层身份 / 核心冲突】。

任务：
表1 功能位清单：功能位（捧场/递刀/对手/情感/镜像/消耗）| 他与主角的关系 | 他的动机 | 退场方式 | 该功能位服务什么目的
表2 主角反差结构：表层身份 | 内核真相 | 反差靠什么维持 | 何时以何种方式被揭穿
表3 关系网功能结构：用"压制者/伪装盟友/镜像者"三个抽象位置画出关系

约束：
① 禁止出现原书人名与外号，用"功能位A（对手型）"表示
② 禁止提取口癖、外形描写、标志互动方式（这些属表达层，进禁区清单）
③ 最后追加「可迁移的功能位 ≤2 个」，每个给出迁移到我的设定后的：身份 / 动机 / 关系（三个维度必须至少换两个）
```

## RD · 移植转化（唯一合法的"借鉴 → 我的"路径）

```
角色：你是结构移植助手。你的任务是把一个抽象结构放进我的世界观，不是翻译。

输入：
  【抽象功能】一句话描述（来自可移植清单，不含原文）
  【我的世界规则】我的 L0 元规则与力量体系
  【我的当前处境】我的主角第 X 章的状态、目标、限制
  【我要融合的其他来源】R0x + R0y + 我的原创设计

任务：按四步输出：
① 抽象化：把这个功能写成一句完全脱离来源的话
② 换外壳：列出至少换了 3 个维度（身份/动机/关系/道具/场景），逐条写清换成什么
③ 重推导：在我的世界规则下，这个桥段"为什么必然发生"——给出因果链，答不上来就明说"不成立"
④ 反向自检：把成品给不知情的人看，还能认出来源吗？（是 → 标记【转化不合格】）

硬约束：
① 输出里不得出现来源书的任何专有名词
② 不得使用"就像……那样"的句式
③ 第③步不成立时，直接输出【建议放弃该条移植】
④ 输出 ≤500 字
```

## RE · 反洗稿自检（成稿后）

```
角色：你是原创合规审查员。你的职责是挑出"可能来自他人作品"的表达。

输入：我的第 X 章正文 + 【禁区清单：绝对不能出现的原文片段/口癖/专有名词】。

任务：
① 逐句比对禁区清单，标出任何近似表达（同义改写也算命中）
② 标出本章中与来源书在"桥段层面"高度相似的段落（即使文字不同）
③ 对每一处给出：【位置】【相似的是什么层（结构/功能/表达）】【风险等级】【改法】

风险分级：
🔴 表达层命中（文字、口癖、金句、专有名词近似）→ 必须改
🟡 功能层高度相似（桥段逻辑几乎一致，只换了名字）→ 必须再加两个维度改造
⚪ 结构层相同（节拍相同）→ 合规，无需处理，但需在移植台账登记

约束：
① 没有问题就写"无"，不要凑数
② 每条必须给可执行改法（换什么、怎么换）
③ 不得让 AI 直接改写——只给方向，我来重写（内环禁止 AI）
```

## 使用顺序

```
拿到一本书 → RA 拆七维 → RB 取节拍 → RC 取功能位
     → 填 03-可移植清单.md（勾要用的）+ 04-禁区清单.md（记不能碰的）
     → RD 逐条转化 → 填 90-移植审批台账.md → 写进我的卷纲/章纲
     → 成稿后 RE 自检 + python tools/ref.py scan
```

**最后提醒**：RA/RB/RC 的产物进 `10-reference/R0x/`，属于**别人的**；RD 的产物进 `02-plot/`，属于**你的**。这两个地方不要混。
